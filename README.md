# Mag Dental Clinic

Landing page premium pentru o clinică stomatologică din Chișinău, Moldova.

## Tech stack

- **Vite** — dev server și build tool
- **HTML / CSS / JS** — vanilla, fără frameworks
- **Google Fonts** — Cormorant Garamond + DM Sans
- **Tabler Icons** — iconițe via CDN

## Structură

```
├── index.html
├── vite.config.js
├── package.json
└── src/
    ├── css/
    │   └── styles.css
    └── js/
        └── main.js
```

## Instalare și rulare

```bash
npm install
npm run dev
```

## Build pentru producție

```bash
npm run build
npm run preview
```

## Secțiuni

- **Hero** — tagline, CTA dublu, statistici rapide
- **Despre noi** — misiune, valori cheie
- **Servicii** — 6 carduri (stomatologie generală, implantologie, ortodonție, estetică, albire, urgențe)
- **De ce noi** — 4 statistici animate
- **Testimoniale** — 3 recenzii pacienți
- **Footer** — adresă, program, contact, social media
